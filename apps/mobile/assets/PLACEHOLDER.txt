KVL School Mobile App — Assets Folder
========================================

Place the following image files here before building:

  icon.png       — App icon (1024x1024 PNG, navy background #1e3a5f with KVL logo)
  splash.png     — Splash screen image (1284x2778 PNG recommended)
  favicon.png    — Web favicon (48x48 PNG)
  adaptive-icon.png — Android adaptive icon foreground (1024x1024 PNG)

You can generate placeholder icons using:
  npx expo-optimize  (after npm install)

Or download the KVL logo assets from the school's brand kit.
